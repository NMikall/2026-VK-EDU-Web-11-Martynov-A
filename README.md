## HW-1 — Вёрстка статического сайта

Статическая HTML/CSS реализация макета веб-сайта вопросов и ответов. Используется Bootstrap.

### Страницы
- `base.html` — общий макет (header, footer, aside)
- `index.html` — главная страница со списком вопросов
- `tags.html` — страница с вопросами по тегу
- `question.html` — страница вопроса (карточка вопроса, список ответов, форма ответа)
- `ask.html` — форма добавления вопроса
- `login.html` — страница авторизации
- `signup.html` — страница регистрации
- `profile.html` — редактирование профиля

### Как открыть
Открыть файл `public/base.html` в браузере.
